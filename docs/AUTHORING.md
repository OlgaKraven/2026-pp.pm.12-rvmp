# Подготовка и проверка материалов

Учебный текст и структура — `content/course.json`; все листинги берутся из файлов `unity-project/Assets/Scripts`. `scripts/build.py` формирует три HTML-раздела, отдельные скачивания кода и демонстрации. `assignment.pdf` — полное задание и методичка; `guide.pdf` — отдельный список областей, согласно импорту EatDoners.

Зависимости: `python -m pip install -r requirements.txt`. Сборка: `python scripts/build.py --release`, проверка: `python scripts/check.py`. Обычная сборка копирует точные проверенные PDF из `materials`; изменение текста, кода или рендера требует `python scripts/build.py --render-pdf` и нового визуального прохода. Отпечаток предотвращает публикацию старого PDF с новым текстом.

Форма Word хранится в `forms/Отчет о выполнении.docx`. Для повторного изготовления из сохранённого мастера установить python-docx 1.2.0 и выполнить `python scripts/build_report.py`, затем обновить поля в Word и проверить все страницы и пробное заполнение. Обычная сборка не перезаписывает уже обновлённый Word файл.

Книжный профиль PDF, локальный Golos Text, размеры блоков и маршрута закреплены в `scripts/design.py`. Увеличение текста меняет число страниц, но не размер шрифта. Рабочие проверки не входят в студенческую выдачу.
