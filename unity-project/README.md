# Кристальный маршрут · ПП.ПМ.12

Unity 6.6 (6000.6.2f1), 2D, Input Manager (Old). Откройте Assets/Scenes/Main.unity, нажмите Play и выберите уровень. Управление: WASD, стрелки, экранные кнопки. Escape включает/снимает паузу.

Цель: собрать кристаллы и войти в портал. Уровни: 3/5/7 кристаллов, 2/4/6 опасностей, 90/80/70 секунд. Три жизни на попытку. Победа открывает следующий уровень; поражение ничего не открывает. Сохраняются доступ, рекорды и громкость. Пауза сохраняет текущую попытку в памяти; новый запуск начинает из меню.

GameRoot содержит LevelManager, WorldBuilder и GameManager. Остальные компоненты и поле создаются во время Play. Для изменения данных остановите Play. Поле редактируется в WorldBuilder.cs, оформление — в VisualTheme.cs.

Папки Library, Temp, Logs, obj, UserSettings и Build в архив не включаются.
